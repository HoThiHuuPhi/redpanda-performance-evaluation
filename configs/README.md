# Configuration Notes

This directory is intended for Redpanda broker configuration files used during the project deployment.

## Expected Contents
- `broker1-redpanda.yaml`
- `broker2-redpanda.yaml`
- `broker3-redpanda.yaml`

## Configuration Scope
Typical configuration artifacts for this project include:
- cluster bootstrap settings
- broker networking configuration
- replication-related settings
- storage and data directory paths
- listener and advertised address definitions

## Recommendation
If you add real configuration files later, remove sensitive values before publishing them.
